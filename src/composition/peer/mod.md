# Peer Protocol composition

Trusted application composition connects public Peer Protocol contracts to
protected local owners. It does not infer grants, installed handlers or private
key handles from peer controls. The authenticated bridge supplies original stream
scope and runs synchronous dependency callbacks on its bounded workers.

The [claim adapter](claims.md) joins original issuer accounting and an explicitly
installed protected decryption port. Transport registration and request plans
remain opt-in; the default server's supported protocols are unchanged.
