# Static Pages errors

`Invalid` (malformed path, media type, manifest or field), `Unsupported`, `NotAvailable` (unknown or unreadable, deliberately indistinguishable), `Limit`, `Storage` and `Unavailable`. Hosted publication errors
map to the matching category (a conflict is `Invalid`; an unknown or effect-possible failure is `Storage`); `NotAvailable` is Services `Denied`. Errors carry no paths, content or peer text.
