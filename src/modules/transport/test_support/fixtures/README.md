# Transport fixtures

`transport-v1.md` is an unchanged snapshot of CR2SE's
[Transport version 1 test vectors](https://github.com/beothorn/CR2SE/blob/8e848eb2e70ef7cd4490a753f9e647fdddcd99fd/modules/transport/pseudocode/TestVectors.md)
at revision `8e848eb2e70ef7cd4490a753f9e647fdddcd99fd`.

Retain all fixed inputs and expected bytes, including both HELLO/AUTH payloads,
public keys and IDs, shared/derived material, and the first protected PING and
PONG. The published private inputs are test data only. Load them through
`test_support::vectors` inside unit tests; do not use them as runtime credentials.

The snapshot is a fixed expected result, not generated by TalkSphere's codecs
or scripted cryptography. Step 2 verifies fixture lengths and composition only;
real signature, key-agreement, derivation and tag verification remains pending.
When adopting a new upstream revision, review the byte changes, retain the
permalink and explain any changed expectations instead of regenerating results
from the implementation under test.

## Build, run and test

These fixtures have no separate executable. From the repository root:

```sh
cargo build --locked
cargo test --locked modules::transport::test_support::vectors
cargo test --locked modules::transport::test_support::socket
cargo run --locked -- --help
```

See [the helper README](../README.md) for the full suite and fixture usage.
