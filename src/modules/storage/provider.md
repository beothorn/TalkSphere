# Storage provider adapter

The adapter exposes the full Storage family through the Services Provider
contract. Composition supplies a recovered admission gate, an unpredictable
ID generator, a coherent clock, finite result bounds and a check capacity.
Registration still requires an independently recognized definition and a
matching requester implementation. Publication must follow owner recovery.

Assessment validates authenticated ownership and current terms before quoting.
Dispatch calls the original-key Storage operations and retains their outcomes.
The separate evidence path reads only the challenged byte under the accepted
check terms. For store the adapter validates and finalizes the prepared template
and delivers the exact recorded result. Ordinary operations use ordinary
participant decisions. Aborts release the original resources.

The adapter also resolves local provider-owned lease metadata for quote pricing.
A node that requests work at other providers supplies independent requester
expectations for those providers.
