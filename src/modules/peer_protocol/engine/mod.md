# Authenticated Peer Protocol execution

The engine joins verified Transport observations to synchronous public module
contracts without running dependencies on the reactor. The [worker pool](worker.md)
bounds running, queued and unread completions. The [stream bridge](bridge/mod.md)
retains original scope/timing, finite framing/output, once-in-flight callbacks,
normal terminal ordering and late owner cleanup.

The [endpoint](endpoint/mod.md) composes complete provided/wanted work/checks,
exact quote consent, explicit original-key cached retries, metadata and independent
Ledger controls over real owners. Protected claim decryption is explicitly
installed by trusted composition. Incoming factories and one-shot outgoing plans
share [logical value/body and per-peer admission](endpoint/resources.md); no peer
message supplies authority, handler code or application input/spending policy.

The [runtime guide](../../../../docs/peer-protocol/RUNTIME.md) and finite example
show explicit registration and real-node composition. Default serve installs no
Peer Protocol factory. [Acceptance evidence](../ACCEPTANCE.md) distinguishes
complete generic responsibilities from standard-family resources, persistent
minimum-node composition and independent interoperability.
