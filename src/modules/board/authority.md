# Local authority

Authority is an issuer owned by trusted composition; creating or sharing it is
an administrative action. New and default create live independent domains.
Grant binds one publisher's exact Identity ID, action and positive byte budget.
Actions are Publish, Read, Cache and Select; none authorizes service execution.
Issuance rejects revoked issuers or a zero budget.

Check requires the original live issuer, exact publisher and action, and bytes
within the budget. Foreign, revoked, wrong-identity and wrong-purpose grants
return Denied; excess bytes return Limit. Revoke permanently invalidates all
issued grants without changing durable state. Dropping the issuer also ends
grant lifetime. Grants have no wire encoding or peer-controlled constructor.
