# Trusted semantic capabilities

Capabilities is supplied by trusted composition and cannot be populated from
peer hints. understands recognizes an exact service/version; terms validates
all applicable family restrictions and exact model arithmetic, returning explicit
Unsupported/Invalid/Limit outcomes. precondition verifies a named condition using
trusted authentication context. local asserts actual provider support for a
provided offering, or requester codec and authorized input for a wanted offering.

assess requires understood schemas/service, local support when publishing, valid
terms and every required precondition. Failure affects this offering; callers
can still discover unrelated offerings. It performs no quote, reservation,
execution, network request or spending. Unavailable refuses all service and local
support and recognizes only cr2se.identity when trusted context is authenticated.
This conservative default is suitable for offline inspection, not a fake provider.
