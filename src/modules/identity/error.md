# Identity error contract

IdentityError distinguishes InvalidInput, Unsupported, IdentityMismatch, InvalidProof, AccessDenied, Unavailable, ResourceLimit, Conflict and OutcomeUnknown. Display returns a fixed secret-free explanation. OutcomeUnknown requires reconciliation because installation may already be durable; it is not permission to create replacement keys. These are local typed errors, not new peer codes.
