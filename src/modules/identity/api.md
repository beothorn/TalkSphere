# Identity api contract

IdentityId contains exactly 32 bytes and compares by those bytes. PublicIdentity has a validated ID and signing public key, read through id and signing_public_key; callers cannot construct a validated value directly. PublicCredential contains identity, a 32-byte persistent encryption public key and 64-byte binding signature; received bindings still require validation. Contact contains expected_id and an optional IP/port endpoint and grants no authentication. CONTRACT_VERSION is one; validate_contract rejects other versions before effects. IdentityProvider associates an opaque Handle and trusted Administration authority with create/load; unfinished default operations return Unavailable and no credential. Creation must eventually mean durable installation of both pairs; loading must never silently regenerate keys.
