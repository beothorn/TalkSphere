# TalkSphere

TalkSphere is a peer-to-peer runtime for trust-based communication and resource sharing.  

The idea is that it is expensive for people you don't trust to communicate with you, but cheap for the ones that you trust.  
Each person has it`s own credit system, and can use it to reach other people and share resources.  
More centralized nodes make "money" not by showing ads, but by using resources such as storage.   

"Money" is actually just credits that can be converted to resources.  
So if you offer 1 giga storage for 1 month, whoever uses needs to pay one credit.  
Credits are not global, but only related to one node.
