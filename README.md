# Talksphere

## Under Construction.  

Talksphere is a server-like implementation of the CR2SE protocol.  
It trades social features for storage.  
It will feature:  
- Message exchanging  
- Public boards  
- Personal pages  

As a paid option it will:
- Offer backup space  

Thanks to the CR2SE protocol, each user can share a bit of storeage on their devices, so the Talksphere is ad free.  
The servers will be paid by selling storage.  

## Clients

Talksphere is compatible with any client implementing the CR2SE protocol.
