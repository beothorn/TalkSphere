# TalkSphere

TalkSphere is a peer-to-peer runtime for trust-based communication and resource sharing.

Current prototype status (Linux):
- Runs one long-lived TCP server per process.
- Accepts simple peer-control messages (`CONNECT` and `MESSAGE`).
- Demonstrates chaining one instance to another and sending a callback message.

For runnable instructions, see:
- `project/TalkSphere/linux/README.md`
- `docs/main.md`
