# Usage  

# Help

`talksphere [--help|help|h]`

# Run 

`talksphere run <listen_port> <peer_port>`

# Start

`talksphere --home ~/dev/talksphere_sandbox/Alice/ start`

Creates the TalkSphere home files without starting the socket service. If the home does not have an identifier yet, it prints:

`A new identifier was created: <identifier>`
